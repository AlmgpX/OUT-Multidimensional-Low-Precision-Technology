# OUT Multidimensional Low-Precision Technology

Автор архитектурной концепции, требований и продуктового направления — **Alex Merqury (AlexMerq)**.
Правообладатель: **Алексей Савельев**; Alex Merqury — творческий псевдоним.
Здесь собраны ключевые реализации OUT Motor и OUT Guard и **[нативные ядра C++17](Native/README.ru.md)**
с DLL, статической библиотекой и проверками совпадения с C#. Исходный C# сохранён для
сравнения и существующей интеграции с Unity. Механизмы — многомерные таблицы низкой
точности, компактные индексы, общие данные и коррекция с памятью состояния.

Добавлен **[OUT FIBER](OUT_FIBER/README.ru.md)**: нативная C++-песочница с выживанием,
движением и поведением NPC, настоящими массивами 3D/4D/5D и измерениями нагрузки.
