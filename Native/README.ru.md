# OUT Guard + OUT Motor — нативный SDK C++17

Вычислительные ядра обоих продуктов перенесены в C++: статическая библиотека,
DLL и C-интерфейс. Для их исполнения C# и .NET не нужны. Архитектура и направление —
**Alex Merqury**, правообладатель — **Алексей Савельев**. Действует [лицензия](../LICENSE).

**Это отдельный нативный SDK, а не автоматически обновлённый Unity-ассет.**
Текущий Unity-проект не изменён. Inspector, GameObject, материалы, GPU-отрисовка и
автоматический поиск костей требуют адаптера к движку. Исходный C# сохранён как
эталон для сравнительных тестов и как существующая Unity-интеграция.

В Guard перенесены защищённые значения, проверка движения, часы, накопление риска,
чтение временной модели, шифрованные сохранения, handshake, бюджеты действий,
проверка файлов и серверная симуляция с геометрией, прыжками, рывками и выстрелами.
Форматы сохранений и протокольной аутентификации проверены на совместимость с C#.
Общая стандартная таблица поведения не копируется в каждого актёра.

В Motor перенесены владение миром и состояниями, цели и кэш 128 движений, постановка
стоп, навигация, события и повреждения, потеря конечностей, падение и восстановление,
физические попадания, RTS-логика, кровь, архетипы и расчёт данных для рендера/рига.
Код использует существующий C++-решатель. Поддерживаются переданные разработчиком
int16-анимации; данные платного ассета не встроены в исходники.

Сборка: `Native\tools\build_windows.cmd E:\OUT_NATIVE_BUILD`.
Результат: `out_native_core.lib`, `out_native.dll`, `out_native.lib` и проверочный EXE.
Проверено на **Windows x64 / MSVC / C++17**; криптография использует Windows CNG.
CMake предоставлен, но на этой машине не запускался. Другие платформы не подтверждены.

Нативный SDK сохраняет границы защиты: клиент может быть модифицирован; обнаружение
аномалий не равно доказанному читу; временная модель не принимает решения о бане.
Нет kernel-, injection-, wallhack- или aimbot-детектора. Общая физика Motor — float,
контакты толпы ограничены бюджетом, произвольный рельеф и коллайдеры движка нужно
интегрировать отдельно. Это не доказательство ускорения или готовности production-backend.

**Платные банки Motor и фиксированная модель Guard в GitHub не опубликованы и не переобучались.**
Синтетические тестовые примеры не заменяют данные продукта. Сборка и применение кода
требуют соответствующих прав; публичная видимость не даёт бесплатную лицензию.
